# projects

## qa-atelier

A personal testing atelier: an experimental workspace for practicing
Android and web UI automation using Kotlin, UIAutomator, and Selenium,
with CI/CD via GitHub Actions and AI-assisted development.

- tech: Kotlin · TypeScript · UIAutomator · Selenium · GitHub Actions
- code: [github.com/tom-xs/qa-atelier](https://github.com/tom-xs/qa-atelier)

## web-form-runner

A lightweight web automation tool for filling and submitting repetitive
forms, built as a practice project for headless browser scripting and
CI-driven regression checks.

- tech: Python · Selenium · GitHub Actions
- code: [github.com/tom-xs/web-form-runner](https://github.com/tom-xs/web-form-runner)

## test-metrics-dashboard

A small data analysis project that parses test-run history into a
dashboard of pass/fail trends and flaky-test hotspots, used to prioritize
what to fix first in a test suite.

- tech: Python · pandas · matplotlib
- code: [github.com/tom-xs/test-metrics-dashboard](https://github.com/tom-xs/test-metrics-dashboard)
